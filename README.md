# Последний круг — стартовый проект

Небольшой браузерный прототип детективной игры: регистрация/вход, три локации, улики, допросы и сохранение прогресса в SQLite.

## Что уже есть
- Frontend: обычные HTML/CSS/JavaScript, без сборщика.
- Backend: FastAPI.
- SQLite: аккаунты и прогресс.
- Данные дела лежат в `backend/story/case-001.json`.
- Пароли хешируются через PBKDF2 из стандартной библиотеки Python.

## Запуск локально

Требуется Python 3.10+.

1. Откройте терминал в папке `last_lap`.
2. Установите зависимости и запустите API:

   ```bash
   python -m venv .venv
   # Windows:
   .venv\\Scripts\\activate
   # macOS/Linux:
   source .venv/bin/activate

   pip install -r backend/requirements.txt
   uvicorn app.main:app --app-dir backend --reload
   ```

3. Во втором терминале запустите frontend из папки проекта:

   ```bash
   python -m http.server 5500 --directory frontend
   ```

4. Откройте `http://127.0.0.1:5500`.

Регистрация требует имя пользователя от 3 символов (латинские буквы, цифры, `_`) и пароль от 8 символов.

## Важно
Это учебный прототип, а не готовая к публичному развёртыванию система. Сессии хранятся в памяти и сбрасываются при перезапуске backend; перед публикацией замените их на устойчивое хранилище сессий, включите HTTPS, добавьте защиту от CSRF и ограничение частоты входа. Не используйте реальные пароли. Финальный виновник/развязка оставлены для доработки: история намеренно не закрепляет виновного за конкретным персонажем.
