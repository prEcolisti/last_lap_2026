# Последний круг

Пиксельный 2D-детектив в браузере. Кейс банка «Центр-инвест», команда «прЕколисты».

**Играть:** http://176.124.223.180/

## Об игре

На ночной гонке болид №7 после пит-стопа перестаёт тормозить и врезается в отбойник. Игрок — детектив, который приезжает на трассу через два дня.

- **Катсцена** (~95 с): гонка с видом сверху, пит-стоп с «лишним» механиком, авария, фото с финиша.
- **Три локации**: место аварии, бокс №7, VIP-ложа с барменом. Детектив ходит по клику, улики попадают в блокнот.
- **Допросы** трёх подозреваемых: ответы печатаются посимвольно, портреты меняют эмоции, новые вопросы открываются по ходу.
- **Финал**: обвинение за столом в комнате допросов. Ошибка — дело провалено, верный ответ — титры с разбором преступления.
- Вход по никнейму и паролю, прогресс сохраняется за аккаунтом.

## Дизайн

- Пиксель-арт в кадре 320×180, масштабируется целым множителем, чтобы пиксели оставались чёткими.
- Ночная гоночная палитра: почти чёрный зелёный фон, асфальт, зелёный акцент `#3dbf72`, красный для опасности. Все цвета — токены в `src/styles/tokens.css`.
- Шрифты: Press Start 2P для заголовков и интерфейса игры, Montserrat для текста.
- У каждого экрана своя музыка, треки плавно сменяют друг друга. Звуки моторов, рации, шагов синтезируются в браузере.
- Адаптив: игра полностью проходится с телефона.

## Стек

- **Vite + React 19 + TypeScript**, react-router-dom.
- **Canvas** — свой движок катсцен: сцены, звуковые события, тряска камеры, субтитры. Трасса — сплайн Catmull-Rom, гонка просчитывается заранее с физикой торможения в поворотах и без наложения машин.
- **Web Audio API** — синтез звуков и музыки.
- Обычный CSS с токенами, без UI-библиотек. Линтер — oxlint.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # сборка в dist/
```

Без настроек аккаунты и прогресс живут в `localStorage`. Чтобы работать с сервером из ветки `databases`, создайте `.env.local` с `VITE_API_URL=http://localhost:8000`.

## Ветки

- `main` — игра.
- `databases` — сервер (FastAPI) и база (PostgreSQL).
- `backend` — первый прототип сервера.
