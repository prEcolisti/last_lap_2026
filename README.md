# Последний круг

Пиксельный 2D-детектив в браузере. Кейс банка «Центр-инвест» — разработка игры. Команда «прЕколисты».

На ночной гонке болид №7 после пит-стопа перестаёт тормозить и на полной скорости врезается в отбойник. Через два дня на трассу приезжает детектив — это игрок. Нужно осмотреть место аварии, бокс команды и VIP-ложу, поговорить со свидетелем, допросить трёх подозреваемых и назвать убийцу. Ошибёшься — дело провалено. Угадаешь — узнаешь, как всё было на самом деле.

## Что мы реализовали

**Аккаунт и прогресс**
- Регистрация и вход по никнейму и паролю — без почты и телефона, как требует кейс.
- Прогресс сохраняется за аккаунтом: просмотренная катсцена, найденные улики, заданные вопросы.
- Вся игра доступна только после входа.

**Вступительная катсцена** (~95 секунд, 12 сцен)
- Старт гонки, круги, скрежет металла, пит-стоп с «лишним» механиком, разгон без тормозов, крик инженера в рацию, авария и фото с финиша.
- Собственный движок на canvas 320×180: сцены, звуковые события, тряска камеры, вспышки, субтитры и подписи к звукам для тех, кто смотрит без звука.
- Пауза (пробел) и пропуск (Esc или кнопка).

**Расследование: три локации, десять пунктов**
- **Место аварии** — четыре улики: асфальт без следов торможения, болид, отбойник, обломки.
- **Бокс №7** — три улики: табель смены, ящик с лишней формой, инструменты для изоляции.
- **VIP-ложа** — кресло спонсора, разговор с барменом и листок со схемой круиз-контроля. Листок открывается только после того, как бармен расскажет о спонсоре.
- Детектив идёт туда, куда нажали, и обходит препятствия (поиск пути). У улики появляется «!» и кнопка «Осмотреть».
- Блокнот с найденным в каждой локации. К подозреваемым можно перейти, только когда закрыты все десять пунктов.

**Допросы**
- Три подозреваемых: пилот №22, механик бокса №7 и спонсор команды.
- Ответы печатаются посимвольно, портрет меняет эмоцию: спокоен, нервничает, лжёт, сломлен.
- Некоторые вопросы открываются только после других. Важное само записывается в блокнот «Показания».

**Финал**
- Когда заданы все вопросы, можно назвать убийцу. Выбранный входит в комнату допросов, садится напротив детектива, и они говорят.
- Неверный выбор — «Ты ошибся.» и возврат на главную.
- Верный — папка с делом на стол, печать «Дело раскрыто» и титры, которые по шагам объясняют, как спонсор убил пилота и какие улики его выдали.

**Звук и музыка**
- Все звуковые эффекты синтезируются в браузере (Web Audio): моторы, шины, рация, гайковёрты, шаги, дверь, печать.
- У каждого экрана своя фоновая музыка, треки плавно сменяют друг друга при переходах (таблица ниже).

**Адаптивность**
- Игра проходится и на компьютере, и на телефоне.
- На телефоне карточки идут столбиком, катсцена растягивается на ширину экрана, а в вертикальной ориентации диалоги переезжают под кадр.
- Подсказки про клавиатуру на сенсорных экранах скрыты.

## Как пройти (спойлер)

<details>
<summary>Развернуть</summary>

1. Посмотрите катсцену: на пит-стопе у машины работают пятеро механиков, а на фото с финиша кресло спонсора в ложе пустое.
2. Осмотрите все улики. В VIP-ложе сначала спросите бармена о гостях, потом о спонсоре — после этого откроется листок на столике.
3. Допросите всех. Механик вспомнит «пятого механика» без бейджа и с чистыми руками, спонсор будет утверждать, что всю гонку просидел в ложе.
4. Назовите убийцу: спонсора.

</details>

## Музыка

| Где | Трек |
| --- | --- |
| Главная, вход, регистрация | Undertale — Once Upon a Time (`public/music/once-upon-a-time.mp3`) |
| Вступительная катсцена, меню локаций | тревога, нарастает с первой сцены (синтез) |
| Подозреваемые, допросы | часы, перебор баса и колокольчик (синтез) |
| Место аварии | Undertale — Premonition (`public/music/premonition.mp3`) |
| Бокс №7 | механический остинато (синтез) |

| Обвинение: ошибка | грустный вальс (синтез), доигрывает и на главной |
| Обвинение: дело раскрыто | сдержанная победная тема (синтез) |

Файлы Undertale в репозиторий не входят: положите их в `public/music/` под этими именами. Пока файла нет, вместо него играет синтезированная замена. Браузер включает звук только после первого нажатия или клавиши.

## Запуск

Нужен Node.js 20+.

```bash
npm install
npm run dev      # дев-сервер на http://localhost:5173
npm run build    # сборка в dist/
npm run preview  # просмотр собранной версии
npm run lint     # oxlint
```

## Стек

Vite, React 19, TypeScript, react-router-dom, обычный CSS с токенами (`src/styles/tokens.css`).

Графика — canvas 320×180, масштабируется целым множителем, чтобы пиксели оставались чёткими. Персонажи, портреты и фоны локаций — PNG. Болиды, фоны катсцены и свет рисуются кодом.

Звук — Web Audio API. Шрифты Press Start 2P и Montserrat подключены локально через `@fontsource`.

## Ветки

- **`main`** — игра (этот фронтенд).
- **`backend`** — сервер на FastAPI + SQLite: регистрация и вход, сохранение прогресса, данные дела. Запуск описан в README той ветки.

Сейчас фронтенд работает на моке в `localStorage` (`src/api/auth.mock.ts`): он повторяет ответы и ошибки будущего API. Чтобы подключить сервер, укажите его адрес в `.env`:

```
VITE_API_URL=https://api.example.ru
```

Тогда приложение само переключится на `src/api/auth.http.ts`. Фронтенд ждёт такой контракт:

| Метод  | Путь             | Тело                     | Ответ             |
| ------ | ---------------- | ------------------------ | ----------------- |
| `POST` | `/auth/register` | `{ nickname, password }` | `{ token, user }` |
| `POST` | `/auth/login`    | `{ nickname, password }` | `{ token, user }` |
| `GET`  | `/auth/me`       | —                        | `user`            |
| `POST` | `/auth/logout`   | —                        | `204`             |

Токен передаётся заголовком `Authorization: Bearer <token>`, формы ответов описаны в `src/api/types.ts`. Ошибки — обычные HTTP-коды с телом `{ "message": "текст для пользователя" }`.

Сервер из ветки `backend` пока устроен иначе: пути с префиксом `/api/auth`, поле `username`, сессия в cookie. Чтобы их подключить, нужно привести контракты к одному виду.

## Структура

```
src/
  api/        слой запросов: контракт с бэкендом, http-клиент, мок
  auth/       контекст авторизации (AuthProvider, useAuth, RequireAuth)
  components/ общие блоки: PageShell, TrackBackdrop, Button, Field, AuthCard, DialogueBox
  pages/      экраны: главная, вход, регистрация, катсцена, локации, подозреваемые, допрос, обвинение
  cutscene/   движок катсцены, сценарии вступления (script.ts) и финала (accusation.ts)
  game/       улики и подозреваемые (story.ts), диалоги (dialogues.ts), локации (locations/),
              болиды, фоны и свет, звук (audio.ts) и музыка (music.ts), прогресс, поиск пути
  assets/     персонажи, портреты с эмоциями, фоны локаций, крупные планы улик
  lib/        валидация форм
  styles/     токены и глобальные стили
```

Маршруты: `/` — главная, `/login` — вход, `/register` — регистрация. Только после входа: `/intro` — катсцена, `/locations` — меню локаций, `/locations/:id` — локация, `/suspects` — подозреваемые, `/suspects/:id` — допрос, `/accuse/:id` — обвинение.
